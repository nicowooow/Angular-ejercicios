# Creación de Angular

requisitos:
- **Node.js**: para ejecutar en desarrollo

## Comandos para la ejecución
- Instalar `Angular` como dependencia global 
```bash
npm i -g @angular/cli
```
- Hacemos que por defecto use pnpm, en lugar npm
```bash
ng config -g cli.packageManager pnpm
```
- Iniciar un proyecto en `Angular`
```bash
ng new nombre-app
```
- Lanzar la aplicacaión en local
```bash
ng serve
```
